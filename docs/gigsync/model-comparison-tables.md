# Model comparison: the full tables

Generated by `node scripts/eval-intent/compare.mjs --split test` from `pnpm eval:intent --json` runs on 2026-11-01;
the narrative and the decision are in [model-comparison.md](model-comparison.md). Every row is the same 978 held-out
test cases. "Old" is the routing prompt and checks before 2026-11-01; "new" adds the reply schema, contacts across
scripts and the per-language prompt (round 1); "round 2" adds the shorter prompt (examples only in the message's
script) and 301 more embedding-router sayings. Ollama runs are 4-bit `Q4_K_M` builds; WebLLM runs are the q4f16
builds a phone downloads, on a MacBook Air M2. "Chain as run" puts the word lists after the model, and, from round 1
on, the embedding router (ADR 0042) before it. "In English (ceiling)" reads every non-English message in a
careful English translation made without seeing its label (model-comparison.md says what that does and does not show).
