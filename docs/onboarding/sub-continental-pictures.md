# Sub-Continental pictures: where they go, and how each is judged

Atishay's direction (15 Nov 2026): use the Sub-Continental illustrations (by Obvious, CC licence, credit required)
for the app's pictures, **only where a picture is needed**. Lists and pickers stay text: the work step is chips, as
Hinge and Tinder show interests, with no pictures.

Source: the "GigSync pictures (samples)" Figma file made in the UI 2 fork session
(`figma.com/design/gBgzFK0P4ybGrawibKIxzN`). Figma's Starter plan ran out of tool calls on 15 Nov, so the drawings
could not be read from there yet.

## Where a picture goes

| Screen                            | Today (Warli drawing)            | Sub-Continental scene wanted                     |
| --------------------------------- | -------------------------------- | ------------------------------------------------ |
| Language (first screen)           | Circle of people, `welcome.svg`  | People from different parts of India greeting    |
| Find work / Find help (role)      | `work.svg`, `help.svg` tiles     | A worker on the way to work; a family at home    |
| Wide-screen side panel (`Frame`)  | Five tiles                       | The same scenes as above, no new ones            |
| Number, code, name (small panels) | `phone.svg`, `code.svg`, `greet` | Keep small or drop: a picture is not needed here |
| Work step                         | None (chips)                     | None                                             |

Credit line, once any is used: "Illustrations: Sub-Continental by Obvious" in the app's About or Terms page.

## The 9/10 check, per picture

Each picture is scored out of 10 and must reach 9 before it ships; Atishay reviews them all at the end.

| Points | Check                                                                                   |
| ------ | --------------------------------------------------------------------------------------- |
| 2      | Fits the screen's meaning at a glance (greeting, going to work, help at home)           |
| 2      | Whole drawing, nothing cut at the edges, no faded or stretched parts                    |
| 2      | Recoloured to the kit: paper `#FAF6EE`, ink `#2B1E17`, terracotta `#A4512B`, tints only |
| 1      | Reads at the size it is shown (a 160 px tall panel on a phone)                          |
| 1      | No text baked into the picture                                                          |
| 1      | Same line weight and style as the other pictures on screen                              |
| 1      | People look like the app's users: Indian, everyday clothes, dignified                   |

## To unblock

Either of these, then the pictures are placed, scored and sent for review:
- Export the frames you like from the Figma file as SVG into a folder in this repo (select → Export → SVG), or
- wait for Figma's monthly tool-call reset, or a paid seat, and the file is read directly.
